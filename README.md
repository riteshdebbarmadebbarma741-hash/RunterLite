## 🔐 What is Runter Lite?

Privacy-first messenger with **zero identifiers**. No phone number. No email. No username. 

Built on the **SMP protocol** (SimpleX-compatible) with post-quantum cryptography.

## ✨ Features

| Category | Features |
|:---|:---|
| 🔒 **Privacy** | No User ID • No Phone • No Email • Anonymous by Default |
| 🔐 **Security** | Double Ratchet • X3DH • Post-Quantum Hybrid • PFS |
| 💬 **Messaging** | Text • Images • Voice • Files • Reactions • Disappearing |
| 👥 **Groups** | Create • Members • Admin • Leave |
| 👻 **Incognito** | Ephemeral Profiles • Decoy Mode • Dead Man's Switch |
| 🌐 **Network** | SMP Relays • Custom Relay • One-Tap Tor • SOCKS5 |
| 🎨 **UI** | Material 3 • OLED Dark • Dynamic Colors • RTL |
